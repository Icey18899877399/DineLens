# 餐前点评独立图件

每个图件分别保存为 PDF、SVG 和 300 dpi PNG，按实际内容裁剪并保留约 1.4 mm 的外边距。逐图源数据在 `source_data/`，图题和说明可用于报告图注。

| 图件 | 内容与口径 |
| --- | --- |
| `fig01_aspect_f1` | **18 个方面的提及识别 F1。** 同一测试集、同一组方面，按位置、服务、价格、环境和菜品排列，各组标题在前，细分方面统一缩进。 |
| `fig02_overall_f1` | **两种模型的三项总体指标。** 方面 Macro-F1 按 18 个方面宏平均。情感 Macro-F1 按 28,362 个人工已提及方面上的三个情感类别宏平均。端到端负面 Micro-F1 使用通过提及门控后的输出，覆盖 88,920 个评论与方面组合。 |
| `fig03_confusion_baseline` | **传统基线三分类混淆矩阵。** 行为人工情感，列为模型预测。格内为行内百分比和实际条数，左侧标注每类人工支持量。 |
| `fig04_confusion_bert` | **联合 BERT 三分类混淆矩阵。** 样本、类顺序、归一化口径和 0–100% 的数值范围与图 3 一致。图 3 由浅黄经薄荷绿、灰蓝过渡到藕紫，图 4 使用蓝色顺序色阶。 |
| `fig05_evidence_candidates` | **共享候选数分布。** 来自 360 个人工标为负面的评论与方面组合，计数为 274、75、11。 |
| `fig06_evidence_example` | **原文定位案例。** 两种方法在一条演示评论中选中同一片段，字符区间采用从 0 开始的半开区间。 |

分类结果来自同一份 ASAP 官方测试集（4,940 条评论）的一次已完成实验。传统基线为 Jieba、TF-IDF 与逻辑回归。矩阵百分比四舍五入到一位小数。候选覆盖为 86/360（23.9%），证据类 Hit@1、字符级 F1 和误高亮率待人工标注。

从项目根目录复现绘图。

```powershell
.\.venv\Scripts\python.exe -m pip install -r reports/requirements-figures.txt
.\.venv\Scripts\python.exe -m reports.plot_evaluation
```
