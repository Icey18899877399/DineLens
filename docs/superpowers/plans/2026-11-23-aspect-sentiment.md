# 餐饮评论方面情感判断实施计划

**目标**：让功能 2 输出全部 18 个方面的提及和情感分数，并在人工标为提及的评论方面组合上计算三分类指标。沿用根目录设计稿和功能 1 的数据划分。

**实现**：保存原始极性标签，复用方面检测和 CLI。传统基线共享 TF-IDF 特征并分方面学习极性。BERT 共享评论编码，输出提及及极性两组 logits。

- [x] 先运行极性指标、掩码梯度与 CLI 契约测试，确认能发现对应功能缺失。
- [x] 让数据加载同时保留原始极性和二值提及矩阵。完成三分类指标、逐方面指标及混淆矩阵。
- [x] 实现传统基线和 BERT 的条件极性。BERT 情感损失屏蔽 `-2`、用验证集极性 Macro-F1 选轮次。
- [x] 以 `--task sentiment` 启用功能 2，保持功能 1 的命令、模型和输出可用。
- [x] 全量验证基线，核对导出、人工标注筛选与指标。用本地小 BERT 验证训练、保存、重载。

## 验证结果

- 8 项测试通过，覆盖未提及方面的损失屏蔽、人工标签筛选、基线与 BERT 联合模型重载。
- 传统基线在官方测试集的 28,362 个已提及方面上取得情感 Macro-F1 0.679879、负面 F1 0.617386、负面召回 0.628639。
- 已复核 88,920 条测试预测及 19 张混淆矩阵。
