# 餐饮评论方面多标签分类实施计划

**目标**：使用 ASAP 的 18 个标签训练、评估并部署方面提及预测，输出五大类下的逐方面分数和二值判定。

**设计依据**：项目根目录的《面向餐饮运营的中文评论痛点诊断系统.md》和对话中确定的功能 1 方案。

**组件**：数据加载、验证集阈值、评估、基线、BERT、命令行。运行目录独立保存可重载的模型、测试指标和逐条预测。

## 实施与验证

- [x] 先写数据与评估测试。覆盖正／中／负都属于提及、五大类下 18 维映射、测试集优先保留、按各标签用验证分数选阈值。
- [x] 先写命令行测试。用小型 ASAP 格式样例训练实际的 Jieba、TF-IDF 和逻辑回归，重新加载模型并校验逐条预测和输出模式。
- [x] 先写 BERT 验证。构造本地极小 BERT 检查点，跑一次实际训练、保存与重新推理，验证 18 维 sigmoid 提及分数。
- [x] 实现数据和评估模块。正式 CSV 原样保留。按文本规范化去重，测试集优先，其次验证集，训练集最后。
- [x] 实现两套训练和推理。基线只在训练集拟合词表。BERT 每条评论编码一次并输出 18 个 logits。以验证集 Macro-F1 选择检查点和阈值。
- [x] 实现测试集导出和单条 JSON 预测。沿用 ASAP 的方面键和评论 ID。
- [x] 运行全量基线。核对 4,940×18 条预测、指标可重算、保存的模型可重载。说明 GPU 训练与网页接入命令。

## 验证结果

- 5 项测试通过，包含 BERT 小模型的实际训练、保存和重载。
- 基线在官方 4,940 条测试评论上取得 Macro-F1 0.759650、Micro-F1 0.799376。
- 88,920 条测试预测已逐条对照人工标签并重算指标。
