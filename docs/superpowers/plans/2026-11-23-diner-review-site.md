# 食客点评网页 Implementation Plan

**目标** 交付一版保存在 D 盘的食客点评页，支持阅读示例点评、方面筛选、原文证据高亮和输入一条评论分析。

**架构** 浏览器使用原生 HTML、CSS 和 JavaScript。Python 本地 HTTP 服务读取已保存的官方测试预测和实验汇总，延迟加载已有的 BERT 和证据抽取器。图片和标题字体随页面保存。

**依据** 本对话中已确认的食客视角、餐桌实拍、暖色配色和首页布局。

- [x] 为评论与预测关联、统计口径、筛选和分页编写测试并验证失败。
- [x] 在 `web/catalog.py` 实现只读数据视图，在 `web/server.py` 接通浏览、原文、单条推理和评估说明。
- [x] 在 `web/public/` 完成实际照片、响应式布局、筛选、原文与分析弹窗。
- [x] 核验真实数据、BERT 联动及桌面和移动布局，补上本地启动说明。

全部 20 项 Python 测试通过。Chromium 实测了 320–1,440 像素宽度、情感筛选与详情定位、分页键盘焦点、单条 BERT 分析和两种证据排序。
