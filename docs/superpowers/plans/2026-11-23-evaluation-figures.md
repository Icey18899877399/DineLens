# 功能 1–3 可视化 Implementation Plan

**目标** 在食客网页的「数据说明」增加模型和证据图，并导出可复用的两张报告主图。

**图表依据** 图 1 以 18 方面识别的成对 F1 为主，辅以同测试集总体分数和两模型情感混淆矩阵。图 2 展示共享候选构成和经核对的演示原评，两项证据算法的正式精度待人工标注。

**技术栈** 网页沿用原生 HTML、CSS、JavaScript 和现有本地 Python 服务。报告图用 Python 和 Matplotlib 导出 SVG、PDF、PNG，附绘图源数据。

- [x] 为同一分割的成对指标、行归一化、样本量和证据原文坐标编写测试。
- [x] 共享结果数据，在网页加入可切换和可逐项查看的图表，保留排行校验与食客页面。
- [x] 生成报告分类比较图、证据诊断图和配套数据。
- [x] 检查桌面和手机交互、图面实际尺寸、矢量文字与指标可追溯性。

核验完成。23 项 Python 测试通过。桌面和 320、390、768 像素视口通过标签切换、F1 刻度对齐、逐项查看、矩阵格子明细和证据方法切换。两张报告图已检查渲染，PDF 内嵌中文字体，SVG 保留可编辑文字，PNG 为 300 dpi。
