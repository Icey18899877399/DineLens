**目标**：针对 ASAP 的 18 个方面，从原评论中抽取负面片段，供网页高亮，并支持成对对比 TF-IDF 余弦排序和 TextRank。

- [x] 先写断句、方面约束、原文偏移、排序对比及补标评估测试。
- [x] 创建 `aspect_detection/evidence.py`。从现有基线加载在训练集拟合的向量器，两种算法使用相同候选。对无法定位证据的样本返回空结果。
- [x] 创建 `aspect_detection/evidence_eval.py`。按方面从 ASAP 抽样，校验人工标注，导出成对实验指标和逐例结果。
- [x] 接入单条评论和功能 2 推理入口，向后保持旧 JSON 契约。为网页保留原文和半开区间。
- [x] 用全量模型做真实推理，核对 360 条补标模板及所有测试。人工留空的样本不产生正式证据跑分。

## 核验结果

- 全部 17 个单元测试和 CLI 测试通过。

- 对 360 条待补标样本核验了官方负面标签和原文坐标。两种方法使用相同候选集合。
